Versión 3.0 — Unificación en PHP, Correcciones y Seguridad Completa
========================================================================
Fecha: 2026-06-06
Hora: 11:32 PM

1. Migración de Flask a PHP:
   - Se reescribió por completo la lógica del panel administrativo de empleados de Python Flask a PHP nativo, eliminando la necesidad de encender la aplicación desde terminal.
   - Nuevos archivos creados:
     * admin_alumnas.php (Gestión de alumnas, registro y activación)
     * admin_agenda.php (Agenda semanal detallada por coach e inscripciones manuales)
     * admin_recepcion.php (Check-in de asistencia diaria de coaches y estadísticas semanales)
   - Esto simplifica la infraestructura: todo corre en Laragon (puerto 80) y es compatible con hosting PHP convencional o Cloudflare Tunnels sin redirecciones de puertos externos.

2. Imagen Real del Estudio:
   - Se reemplazó la imagen genérica de fondo en el Hero section de index.php por 'assets/images/estudio.jpeg', manteniendo el filtro linear-gradient original para legibilidad.

3. Re-estructuración y Corrección de Horarios:
   - Se vació e inicializó la tabla 'horarios' con las clases semanales reales:
     * Stephanie: Lunes a viernes de 6:00 y 7:00 am, 5:00, 6:00, 7:00 y 8:00 pm.
     * Fatima: Lunes, miércoles y viernes a las 8:00 am.
   - Modificado assets/js/app.js para añadir la franja horaria '06:00' al calendario del cliente.

4. Módulo de Planes y Paquetes:
   - Se cambió el distintivo de "Más Popular" al paquete de 12 clases (antes era el de 8).
   - Se ordenaron los planes de menor a mayor en base a sus clases incluidas, eliminando la lógica de código que insertaba manualmente el plan de 20 clases en el medio.

5. Mejoras de Interfaz (UI/UX) y Botones:
   - Se separaron los botones del Hero section de index.php usando Flexbox con espacio (gap) responsivo.
   - El botón "Registrarme a Clases" ahora redirige a login.php?tab=register.
   - Implementado JS en login.php para cambiar automáticamente de pestaña al detectar '?tab=register' o el hash '#register'.

6. Corrección en Inicio de Sesión de Coaches y Navegación:
   - Al ingresar credenciales correctas en login.php, los coaches ya no son redirigidos al puerto 5000 local, sino directamente a admin_alumnas.php dentro del mismo sitio PHP.
   - Implementado el patrón PRG (Post-Redirect-Get) guardando errores en sesión para evitar que el navegador muestre "Confirmar reenvío de formulario" al ir hacia atrás o recargar la página.

7. Diseño de Coaches Unificado:
   - Las tres nuevas páginas de administración PHP heredan el sistema de diseño completo de clientes (tipografías Inter y Cormorant Garamond, colores sage green, marrón, sombras tenues y bordes planos).

8. Seguridad y Validación Visual:
   - Las páginas de administración PHP están protegidas mediante $_SESSION['coach_id'], bloqueando cualquier acceso no autorizado por cambio de URL.
   - Se implementó validación en cliente (JS) para todos los formularios. Si un usuario deja campos requeridos vacíos o escribe un formato de teléfono incorrecto (distinto a 10 dígitos), el submit se detiene y las casillas se tornan en color rojo de advertencia.

9. Sincronización Automática:
   - Todos los archivos nuevos y modificados de scratch fueron sincronizados a la carpeta de producción en C:\laragon\www\balancebarre.

Versión 3.1 — Horario Visual, Auto-asignación Secuencial y Panel Persistente
========================================================================
Fecha: 2026-06-07
Hora: 08:40 PM

CAMBIO 1: Selector de Clases con Formato de Horario Semanal ('registro.php')
   - Archivo modificado: registro.php, assets/js/clases-registro.js
   - Qué se hizo:
     * Se reemplazó el selector de clases de tarjetas individuales (cards) por una grilla
       de horario semanal idéntica a la de horarios.php (schedule-grid).
     * Las clases se muestran en una tabla visual de Lunes a Sábado con las horas en el eje
       vertical, exactamente como el calendario público de horarios.php.
     * En modo manual, el usuario toca directamente las celdas del horario para seleccionar
       sus clases. Las celdas seleccionadas se marcan con un borde verde y el texto "✓ Seleccionada".
     * Se agregaron estilos CSS para celdas seleccionables (.selectable), seleccionadas (.selected)
       y deshabilitadas (.disabled-class) dentro del schedule-grid.

CAMBIO 2: Filtro de Hora de Clase ('registro.php')
   - Archivo modificado: registro.php
   - Qué se hizo:
     * Se añadió un dropdown "Hora de Clase" junto al filtro de coach existente en la
       sección de "Filtros de Horario (Opcional)".
     * Las opciones del dropdown se populan dinámicamente desde las horas únicas disponibles
       en los horarios del sistema.
     * Al seleccionar una hora, la grilla de horario se filtra para mostrar solo las clases
       de esa franja horaria. El filtro funciona tanto en modo manual como automático.

CAMBIO 3: Lógica de Auto-asignación Secuencial Lun→Vie ('reservaciones_helper.php')
   - Archivo modificado: config/reservaciones_helper.php
   - Qué se hizo:
     * Se reescribió la función autoAsignarHorarios() para asignar clases de forma
       estrictamente secuencial: una clase por día, de Lunes a Viernes, hasta cubrir
       el número de clases del paquete.
     * El filtro de hora se aplica directamente en la consulta SQL (antes se filtraba en PHP),
       mejorando la eficiencia.
     * Si el paquete requiere más de 5 clases, el sistema continúa en la siguiente semana
       con el mismo patrón Lun→Vie.
     * Se muestra un mensaje de error claro si no hay suficientes cupos con la hora seleccionada.

CAMBIO 4: Navegación Persistente "Mi Panel" ('registro.php')
   - Archivo modificado: registro.php
   - Qué se hizo:
     * Se actualizó la barra de navegación de registro.php para incluir los mismos enlaces
       condicionales por sesión que tienen index.php y horarios.php.
     * Ahora cuando una alumna está logueada, siempre aparece el enlace "Mi Panel" en la
       navegación sin importar en qué módulo esté. Antes solo se mostraba "Clases" y
       "Cerrar Sesión" de forma fija sin respetar el estado de sesión.
